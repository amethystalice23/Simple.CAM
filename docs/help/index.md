# Welcome to simple.cam

simple.cam turns a 3D model into the [G-code](glossary.md#g-code) a
Carvera CNC cuts. Model in one end, machine-ready file out the other.

*In 3D printing terms:* it's the slicer of the CNC world. Your
slicer doesn't run the printer — it plans the moves and hands them
over. simple.cam plans the cuts and hands them to the Carvera
Community Controller, which drives the machine.

## Who it's for

You, probably: comfortable around a printer and a slicer, new to
spinning sharp things at 24,000 RPM. You don't need machining
experience — you need the vocabulary, and that's what this help is
for. Every new term links to the [glossary](glossary.md).

If you've never run a CNC at all, start with the machine's own
safety and setup material first. The software is the safe part.

## How the work flows

1. **Model** — drop an STL in, set up your [stock](glossary.md#stock)
   (the blank you cut from).
2. **Plan** — add operations: one [toolpath](glossary.md#toolpath) per
   job to do. The app previews every one.
3. **Cut** — export the G-code and open it in the Carvera Community
   Controller. The machine does the rest.

## How this help works

- **Getting started** — your first cut, end to end.
- **Concepts** — the learn-once ideas (feeds and speeds, allowances,
  the 4th axis) that every op assumes.
- **Operations** — one page per op: what it's for, when you'd use it,
  and a step-by-step with screenshots.
- **Reference** — shared fields, the tool library, controls.
- **Tutorials** — complete example jobs built from scratch.
- **Glossary** — every term in plain language.

Start with [your first cut](getting-started/your-first-cut.md), or
jump straight to the op you're curious about.
