# Keyboard shortcuts and mouse gestures

There is exactly one keyboard shortcut in simple.cam, by design —
**Escape** closes whatever dialog is open (About, Export, Calibration,
Simulate, Help, the tool preset table, the Layers dropdown).

Everything else is mouse:

| Gesture | What it does |
|---|---|
| Left-drag on empty viewport | Orbit the camera |
| Scroll | Zoom |
| Click a model face / circle | Select that feature (Measure mode) |
| Click a second feature | Shows the distance between the two |
| Right-click | Clear selection and measurements |
| Shift + left-drag | Rubber-band box select (adds to selection) |
| Click a navcube face | Snap the camera to that named view |
| Drag the slice-plane pill | Move the slice pocket's cut plane |

Feature selection is how ops get their targets: arm **Select
features** on an op, click faces/holes in the viewport, and they
become that op's cut region.
